# EcoScan 🌿 (Хакатон-проект)

Мобильное приложение для экологического мониторинга и экспресс-анализа мусора в Казахстане с помощью Vision-нейросети Groq (`qwen/qwen3.8-27b`).

## 💡 О проекте
Пользователь фотографирует мусор на улице или выбирает фото из галереи. Нейросеть анализирует изображение и формирует отчёт:
1. **Шкала загрязнения (от 1 до 10)** с цветовой индикацией и уровнем («Слабое», «Среднее», «Высокое», «Критическое»).
2. **Типы отходов** (пластик, стекло, строительный мусор, опасные отходы, бумага, органика) в виде интерактивных чипов с иконками.
3. **Вред для Казахстана** с тремя отдельными блоками:
   - 🌿 **Природа и фауна Казахстана** (степи, реки, горы, флора и фауна)
   - 🩺 **Здоровье людей** (микропластик, бактерии, токсины)
   - 💼 **Экономический ущерб** (бюджет муниципалитетов, туризм, рекультивация)
4. **Совет эколога** с практическими рекомендациями по утилизации и обращениями (нацпрограмма *«Таза Қазақстан»*, раздельный сбор, спецпункты).
5. **Состояние «Мусора нет»** (при `is_trash = false`) с сообщением о чистой окружающей среде.

---

## 🔑 Конфигурация API
Ключ Groq API зашит напрямую в конфигурации (`EcoConfig.kt`), никаких дополнительных диалогов ввода ключа нет:
- **Модель:** `qwen/qwen3.8-27b`
- **Эндпоинт:** `https://api.groq.com/openai/v1/chat/completions`
- **Таймаут:** 30 секунд с автоматическим повтором при сбое парсинга.

## 🛠 Сборка APK и тестирование

### Сборка Debug APK:
```bash
gradle assembleDebug
```
Файл APK будет доступен в:
```
app/build/outputs/apk/debug/app-debug.apk
```

### Запуск тестов:
```bash
gradle testDebugUnitTest
```
